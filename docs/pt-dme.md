# PT-DME：基于 Delaunay 三角剖分与极大独立集的并行三元 DME 算法实现说明

## 1. 任务目标

请在现有 CTS 时钟树拓扑构造代码中，实现一种基于三角剖分的并行三元合并算法：

**Parallel Triangular DME（PT-DME）**

算法总体思想：

1. 将当前尚未合并的活动节点作为输入点集。
2. 对活动节点进行二维 Delaunay 三角剖分。
3. 从三角剖分结果中选择一组顶点互不重叠的三角形，构成一个极大独立集（Maximal Independent Set，MIS）。
4. 对独立集中的三角形分别执行三元 DME 合并。由于这些三角形没有共享顶点，因此可以并行执行。
5. 未参与本轮合并的活动节点全部保留，进入下一轮，不允许丢弃。
6. 将新生成的三元根节点与未合并节点组成新的活动节点集合，继续迭代。
7. 当只剩两个活动节点时，调用现有的二元 DME 完成最后一次合并。

本任务首先实现一个正确、确定性、可测试的几何拓扑版本。不要在第一版中擅自引入复杂的 RC 优化、缓冲器插入或延迟区间传播算法。

---

## 2. 算法约束

实现必须遵守以下约束：

- 每个原始 sink 必须且只能属于最终树中的一棵子树。
- 每轮三元合并所使用的三角形之间不能共享顶点。
- 未参与本轮合并的活动节点必须保留到下一轮。
- 不允许因为某个节点未进入独立集而删除该节点。
- 每次三元合并必须生成一个新的活动根节点。
- 每次二元备用合并必须使活动节点数量减少 1。
- 每次三元合并必须使活动节点数量减少 2。
- 最终拓扑必须连通、无环。
- 算法结果必须具有确定性：相同输入和相同参数应产生相同的拓扑结果。
- 不允许把“极大独立集”错误实现为“最大独立集”。

这里的极大独立集指：当前选出的三角形集合中，任意两个三角形都不共享顶点，并且不能再加入任何一个未选择的三角形而不破坏这一性质。

它不要求所选三角形数量达到全局最大值。

## 3. 数据结构

根据现有工程的数据结构进行适配，但必须保留以下信息。

### 3.1 Point

```cpp
struct Point {
    double x;
    double y;
};
```

### 3.2 ActiveNode

表示当前一棵尚未合并完成的子树。

```cpp
struct ActiveNode {
    int id;

    // 当前子树的代表汇合位置
    Point pos;

    // 当前子树的负载
    double capacitance;

    // 延迟区间。第一版可以暂时不参与几何优化
    double delay_min;
    double delay_max;

    // 当前子树在最终拓扑中的根节点 ID
    int tree_root;

    // 连续等待未参与合并的轮数
    int wait_rounds;
};
```

注意：

- ActiveNode 不一定是原始 sink，也可能是前几轮生成的子树。
- 未参与合并的 ActiveNode 必须整体保留。
- 不允许只保留 pos 而丢失原有子树的拓扑信息。
- 新生成的三元根节点应创建新的 tree_root。

### 3.3 Triangle

```cpp
struct Triangle {
    int v[3];

    // 三角形的几何合并代价
    double cost;
};
```

三角形的三个顶点必须引用当前 ActiveNode 数组中的有效索引。

### 3.4 MergeResult

建议将每次合并结果封装起来：

```cpp
struct MergeResult {
    ActiveNode new_node;

    // 新建的拓扑节点和边
    // 根据现有工程的树结构实现
};
```

并行计算时，每个线程应返回独立的 MergeResult，禁止多个线程直接修改共享拓扑容器。

## 4. 每轮算法流程

输入：

```cpp
vector<ActiveNode> active_nodes;
```

输出：

```cpp
vector<ActiveNode> next_nodes;
```

每轮按照以下步骤执行。

### Step 1：终止条件判断

设当前活动节点数量为 N。

- N == 0：返回空结果。
- N == 1：直接返回该节点。
- N == 2：调用普通二元 DME 合并，生成最终根节点并结束。
- N > 2：进入三角剖分流程。

### Step 2：重复坐标处理

Delaunay 三角剖分通常不适合直接处理多个完全重合的点。

因此，在三角剖分前：

1. 检查活动节点是否存在重复坐标。
2. 对相同坐标的活动节点，按照节点 ID 升序确定处理顺序。
3. 对重复坐标的子树执行确定性的零长度二元 DME 合并。
4. 合并后的节点作为新的活动节点。
5. 重新检查活动节点数量。

零长度合并必须保留所有原始子树，不得丢失负载和拓扑信息。

不要通过给重复坐标随机添加微小扰动来处理重复点。

### Step 3：共线退化处理

如果所有活动节点共线，不能直接依赖二维 Delaunay 三角剖分。

处理方式：

1. 判断点集是否共线。
2. 选择变化范围较大的坐标轴作为主坐标轴。
3. 按主坐标排序。
4. 如果主坐标相同，继续按另一坐标排序。
5. 最后按节点 ID 排序。
6. 从排序后的节点中，每三个连续节点组成一个不重叠的三元组。
7. 每组三元组执行三元合并。
8. 剩余 1 或 2 个节点原样保留，进入下一轮。

例如：

```text
A B C D E F G H

本轮合并：
(A, B, C)
(D, E, F)

本轮保留：
G, H
```

如果不足三个节点，则直接保留，进入后续终止判断或二元合并流程。

### Step 4：Delaunay 三角剖分

对当前活动节点的代表位置进行二维 Delaunay 三角剖分。

要求：

- 使用成熟、稳定的 Delaunay 实现。
- 三角形顶点必须映射回原始 ActiveNode 索引。
- 不允许丢失任何活动节点。
- 允许某些活动节点没有出现在任何三角形中，这些节点必须在后续 carry-over 阶段保留。
- 对三角剖分结果进行规范化，保证三角形顶点顺序和三角形整体顺序确定。

如果三角剖分失败或无法产生有效三角形，应进入确定性的退化处理流程，不能直接丢弃节点或终止整个算法。

### Step 5：计算三角形合并代价

对每个三角形 T：

```text
T = (A, B, C)
```

计算其三元合并几何代价。

第一版定义：

\[
Cost(T)=F(T)
\]

其中：

\[
F(T)=\min_{R\in\Gamma(T)}
\max\{d_1(R,A),d_1(R,B),d_1(R,C)\}
\]

曼哈顿距离定义为：

\[
d_1(P,Q)=|P_x-Q_x|+|P_y-Q_y|
\]

\(\Gamma(T)\) 是本方案定义的候选曼哈顿路径集合，具体计算方法见第 5 节。

第一版只使用几何代价，不引入未经标定的电气权重。

### Step 6：三角形优先级排序

所有三角形按照以下规则进行确定性排序：

1. Cost 较小的三角形优先。
2. Cost 相同时，三角形三个顶点中最大 wait_rounds 较大的优先。
3. 仍然相同时，将三个顶点 ID 升序排列后，按照字典序升序比较。

注意：

等待轮数越多，优先级越高。

此规则用于减少部分活动节点长期无法参与合并的问题。

### Step 7：贪心构造极大独立集

建立：

```cpp
vector<bool> used(active_nodes.size(), false);
vector<Triangle> selected;
```

按照已经排好序的三角形列表执行：

```cpp
for (const Triangle& t : triangles) {
    int a = t.v[0];
    int b = t.v[1];
    int c = t.v[2];

    if (!used[a] && !used[b] && !used[c]) {
        selected.push_back(t);

        used[a] = true;
        used[b] = true;
        used[c] = true;
    }
}
```

这样得到的 selected 就是一个确定性的极大独立集。

必须满足：

对于 selected 中任意两个不同三角形 \(T_i,T_j\)：

\[
V(T_i)\cap V(T_j)=\varnothing
\]

其中 V(T) 表示三角形的三个顶点集合。

此外，贪心扫描结束后，所有未选择的三角形都必须至少与一个已选择的三角形共享顶点。

注意：这里的独立性是基于共享活动节点顶点定义的，不是基于三角形是否相邻或几何距离定义的。

### Step 8：执行并行三元合并

selected 中每个三角形对应一次独立的三元合并。

由于 selected 中的三角形没有共享顶点，因此这些合并可以并行执行。

建议接口：

```cpp
Point compute_ternary_root(
    const ActiveNode& a,
    const ActiveNode& b,
    const ActiveNode& c
);

MergeResult merge_three(
    const ActiveNode& a,
    const ActiveNode& b,
    const ActiveNode& c
);
```

要求：

- 每个三角形独立计算自己的根位置。
- 每个三角形独立生成拓扑结果。
- 不同线程不能直接修改共享拓扑容器。
- 并行任务完成后，按照 selected 的确定性顺序统一分配新节点 ID。
- 最终合并结果的顺序必须确定。

### Step 9：Carry-over 未合并节点

这一阶段非常重要。

本轮没有参与任何三元合并的活动节点，必须全部保留。

```cpp
vector<ActiveNode> next_nodes;

// 先加入本轮生成的三元根节点
for (const MergeResult& result : merge_results) {
    next_nodes.push_back(result.new_node);
}

// 再加入未参与合并的旧活动节点
for (int i = 0; i < active_nodes.size(); ++i) {
    if (!used[i]) {
        ActiveNode node = active_nodes[i];

        node.wait_rounds++;

        next_nodes.push_back(node);
    }
}
```

新生成的三元根节点：

```cpp
new_node.wait_rounds = 0;
```

旧节点必须保留：

- 原始子树拓扑；
- 代表位置；
- 电容负载；
- 延迟信息；
- tree_root；
- 节点身份。

不能把未合并节点重新创建为普通 sink，也不能重置其拓扑信息。

### Step 10：检查本轮进度

如果本轮选出的三角形数量为 k，则：

\[
N_{\text{next}}=N-2k
\]

这是因为每个三元合并将三个活动节点变成一个新活动节点，活动节点数量减少 2。

如果：

```cpp
selected.empty()
```

说明本轮无法找到可执行的三元合并。

此时必须触发二元 DME 备用策略：

1. 在当前活动节点中选择曼哈顿距离最近的一对。
2. 如果距离相同，按节点 ID 字典序确定。
3. 调用现有二元 DME 合并。
4. 将新生成的活动节点与其他未参与合并的节点组成下一轮集合。

一次二元合并后：

\[
N_{\text{next}}=N-1
\]

不能因为本轮没有三元合并而直接退出算法。

## 5. 三元根节点的几何计算

这是本算法最重要的几何部分，必须严格按照以下定义实现。

### 5.1 输入

三个活动节点：

\[
A=(x_A,y_A)
\]

\[
B=(x_B,y_B)
\]

\[
C=(x_C,y_C)
\]

输出一个三元合并根节点位置：

\[
R=(x_R,y_R)
\]

### 5.2 选择最近顶点对

计算三个顶点对的曼哈顿距离：

\[
d_{AB}=d_1(A,B)
\]

\[
d_{AC}=d_1(A,C)
\]

\[
d_{BC}=d_1(B,C)
\]

选择距离最小的顶点对作为第一合并对。

如果距离相同，按照两个顶点的 ID 排序后的字典序决定。

为了后续表述方便，将最近点对记为 A、B，剩余点记为 C。

### 5.3 构造 A-B 的 L 型路径

A、B 之间有两种 L 型路径：

- HV：先水平移动，再垂直移动。
- VH：先垂直移动，再水平移动。

两条路径的曼哈顿长度相同。

第一版固定选择 HV 作为 A-B 的路径。

如果现有工程必须同时考虑路径方向，也可以保留 VH，但必须使用确定性规则选择，不能随机选择。

### 5.4 计算 A-B 折线中点 M

中点必须按照 L 型折线的累计曼哈顿长度计算。

设：

\[
L=d_1(A,B)
\]

HV 路径由水平段和垂直段组成：

\[
L_h=|x_B-x_A|
\]

\[
L_v=|y_B-y_A|
\]

总长度：

\[
L=L_h+L_v
\]

从 A 沿折线走过长度 \(L/2\)，得到 M。

如果：

\[
L/2\leq L_h
\]

则 M 位于水平段：

\[
M=(x_A+\operatorname{sgn}(x_B-x_A)L/2,\ y_A)
\]

否则 M 位于垂直段：

\[
M=(x_B,\ y_A+\operatorname{sgn}(y_B-y_A)(L/2-L_h))
\]

如果 L 为 0，则：

\[
M=A
\]

不要使用简单的端点坐标平均值代替折线中点。

### 5.5 构造 M-C 的候选 L 型路径

构造两条候选路径：

- HV：从 M 水平移动到 C 的 x 坐标，再垂直移动到 C。
- VH：从 M 垂直移动到 C 的 y 坐标，再水平移动到 C。

将两条路径上的线段分别加入候选路径集合：

\[
\Gamma(T)
\]

注意：候选路径集合是有限的水平、垂直线段集合，不是整个二维平面。

### 5.6 在候选路径上寻找根节点

定义目标函数：

\[
F(R)=\max
\left\{
d_1(R,A),
d_1(R,B),
d_1(R,C)
\right\}
\]

在候选路径集合上求：

\[
R^*=\arg\min_{R\in\Gamma(T)}F(R)
\]

对每条水平或垂直线段参数化：

\[
P(t)=P_0+t(P_1-P_0),\quad t\in[0,1]
\]

计算：

\[
f(t)=F(P(t))
\]

该函数是一维凸的分段线性函数。

实现要求：

1. 对每条候选线段分别求解。
2. 使用确定性的一维凸搜索。
3. 建议固定执行 80 次区间收缩迭代，或使用经验证的等价精确分段线性最小化方法。
4. 搜索停止后计算候选位置的 F 值。
5. 比较所有候选线段得到的结果，选择 F 最小的点。

数值处理要求：

- 使用 double。
- 定义统一的几何容差 EPS。
- 处理水平段、垂直段长度为 0 的情况。
- 不允许搜索结果跑出原始候选线段。
- 不允许用未经验证的近似公式直接计算根节点。

如果多个候选位置的 F 值在 EPS 范围内相同，则依次使用以下规则打破平局：

1. 选择距离 M 最近的点。
2. 如果仍相同，选择 x 坐标较小的点。
3. 如果仍相同，选择 y 坐标较小的点。

最终得到：

\[
R^*=(x_R,y_R)
\]

需要明确：该定义只保证在指定候选路径集合上寻找最小最大曼哈顿距离点，不保证它是整个二维平面上的全局最优点。

### 5.7 生成三条分支连接

从 R 分别向 A、B、C 生成曼哈顿连接。

每条连接可以采用 HV 或 VH 两种路径。

第一版固定采用 HV：

1. 从 R 水平移动到子树根节点的 x 坐标。
2. 再垂直移动到子树根节点。

如果某段长度为 0，则不创建冗余拓扑节点。

每条分支都必须连接到对应的原始子树根节点，不能只连接到其几何代表点而丢失子树关系。

## 6. 三元合并函数

建议实现：

```cpp
MergeResult merge_three(
    const ActiveNode& a,
    const ActiveNode& b,
    const ActiveNode& c
);
```

执行步骤：

1. 调用 compute_ternary_root() 计算 R。
2. 创建新的三元汇合拓扑节点。
3. 将 A、B、C 对应的子树连接到 R。
4. 记录每条连接的曼哈顿路径。
5. 更新新活动节点的代表位置。
6. 汇总子树负载和其他必要属性。

第一版负载汇总：

\[
C_R=C_A+C_B+C_C
\]

如果需要一个简单的单位线延迟 proxy，可以使用：

\[
D_{\min,R}=
\min_i
\left(D_{\min,i}+d_1(R,P_i)\right)
\]

\[
D_{\max,R}=
\max_i
\left(D_{\max,i}+d_1(R,P_i)\right)
\]

其中：

- \(P_i\) 是第 i 棵子树的代表位置；
- \(D_{\min,i}\)、\(D_{\max,i}\) 是子树已有的延迟区间。

注意：上述延迟计算只是简化的线长 proxy，不是真实 RC 延迟模型。第一版不要把它当成经过物理校准的时钟延迟。

## 7. 主循环伪代码

必须按照以下逻辑实现，不允许改变未合并节点的保留机制。

```text
function PT_DME(active_nodes):

    while active_nodes.size() > 2:

        1. 处理重复坐标

        2. 如果所有节点共线:
               按主坐标排序
               每三个连续节点构成一个三元组
               执行三元合并
               剩余 1~2 个节点 carry-over
               active_nodes = next_nodes
               continue

        3. triangles = DELAUNAY(active_nodes)

        4. 对每个 triangle:
               计算三元合并代价 Cost(T)

        5. 按确定性优先级排序 triangles

        6. selected = GREEDY_MAXIMAL_INDEPENDENT_SET(triangles)

        7. 如果 selected 为空:
               选择最近的两个活动节点
               执行一次二元 DME
               其他节点原样保留
               active_nodes = next_nodes
               continue

        8. used = 所有 selected 三角形顶点的集合

        9. 并行执行:
               对 selected 中每个三角形:
                   result = MERGE_THREE(A, B, C)

       10. next_nodes = 所有新生成的三元根节点

       11. 对每个未被 used 的旧活动节点:
               保留该节点
               wait_rounds++
               加入 next_nodes

       12. 检查:
               next_nodes.size() == active_nodes.size()
                                         - 2 * selected.size()

       13. active_nodes = next_nodes

    if active_nodes.size() == 2:
        return BINARY_DME(active_nodes[0], active_nodes[1])

    if active_nodes.size() == 1:
        return active_nodes[0]

    return empty
```

## 8. 确定性要求

以下情况必须具有确定性：

- 重复坐标节点的处理顺序；
- Delaunay 三角形顶点的规范化顺序；
- 三角形代价相同的排序；
- 三角形 wait_rounds 相同的排序；
- 最近顶点对的选择；
- L 型路径方向的选择；
- 凸搜索的停止条件；
- 最优根节点相同情况下的平局处理；
- 最近二元合并对的选择；
- 新节点 ID 分配顺序；
- 并行任务完成后的结果合并顺序。

不要依赖线程执行完成顺序决定最终节点 ID 或树结构。

## 9. 并行实现要求

三角形独立集中的每个三角形可以并行计算。

推荐采用以下结构：

```text
主线程：
    Delaunay
    三角形排序
    构造 MIS
    生成 selected

并行线程：
    对 selected 中的每个三角形:
        计算三元根位置
        生成局部 MergeResult

主线程：
    按 selected 原始顺序收集结果
    统一分配拓扑节点 ID
    统一写入拓扑结构
    carry-over 未合并节点
```

不要在并行线程中：

- 同时修改共享 vector；
- 同时修改共享树结构；
- 同时修改全局节点 ID 计数器；
- 修改其他三角形使用的 ActiveNode。

因为 MIS 已保证 selected 中没有共享活动节点，因此各个三元合并的几何计算和局部拓扑构建互不冲突。

## 10. 复杂度要求

设当前活动节点数量为 N。

每轮主要操作：

| 操作 | 复杂度 |
|---|---:|
| Delaunay 三角剖分 | O(N log N) |
| 三角形数量 | O(N) |
| 三角形代价计算 | O(N) |
| 三角形排序 | O(N log N) |
| 贪心 MIS | O(N) |
| 三元根节点计算 | O(N) |
| Carry-over | O(N) |

因此单轮复杂度：

\[
O(N\log N)
\]

总复杂度应写为：

\[
O\left(\sum_t N_t\log N_t\right)
\]

其中 \(N_t\) 是第 t 轮的活动节点数量。

不要直接宣称总复杂度为 \(O(N\log^2N)\)。

原因是极大独立集不保证每轮都能合并固定比例的活动节点。在某些极端输入下，每轮可能只完成少量三元合并。

第一版允许每轮重新构建 Delaunay。确认算法正确后，再考虑增量式三角剖分优化。

## 12. 每轮必须执行的断言

每轮结束后至少检查：

### 活动节点数量

如果本轮有 k 个三元合并：

\[
N_{\text{next}}=N-2k
\]

如果本轮执行一次二元备用合并：

\[
N_{\text{next}}=N-1
\]

### 三角形独立性

对于任意两个 selected 三角形：

\[
V(T_i)\cap V(T_j)=\varnothing
\]

### 节点覆盖

每个旧活动节点必须满足：

- 被某个 selected 三角形使用；或
- 被保留到下一轮。

不允许出现第三种情况。

### 树结构

最终结果必须满足：

- 每个原始 sink 恰好出现一次；
- 每个内部节点连接关系正确；
- 最终树连通；
- 最终树无环；
- 所有合并操作都能追溯到原始 sink。
